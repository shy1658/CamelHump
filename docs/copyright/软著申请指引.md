> 面向 CamelHump V1.1.1。材料已全部生成完毕，本文档只讲「怎么交」。
>
> **先读这一条**：2026 年 3 月 15 日起，软著登记执行新规，新增了
> **「未使用 AI 开发编写代码、撰写文档或生成登记申请材料」** 的手抄承诺，

> 请务必先看完再决定是否提交。

## 二、⚠️ 先看清楚这条红线

新规原文（2026-03-15 起施行的优化后申请表）：

> 申请人须手抄写登记相关声明内容，确认软件为**独立开发**、
> **未使用 AI 开发编写代码、撰写文档或生成登记申请材料**，
> 保证申请材料真实、软件功能合规……

同时，版权中心明确将以下列为「非正常申请」并从严审核：
**「材料失范：提交 AI 生成的模板化申报材料，严重扰乱正常审核秩序」**，
以及「弄虚作假：申请材料抄袭造假、内容与软件实际功能脱节」。

### 这对 CamelHump 意味着什么

本项目的代码是**人机协作**产出的：
架构设计、模块划分、技术选型、问题定位与取舍由人（你）决定并驱动，
但具体代码实现由 AI 助手编写。

按字面标准，这**不完全符合**「未使用 AI 开发编写代码」的承诺。

### 三个选项

| 选项 | 做法 | 风险与代价 |
| --- | --- | --- |
| **A. 不申请软著** | 华为应用市场上架中软著是**非必选资质**（《应用资质审核要求》明确标注），直接跳过 | **零风险**。仅失去高新/双软/补贴/投标加分 |
| **B. 自行申请并手抄承诺** | 按新规手抄「未使用 AI 开发编写代码」 | ⚠️ 承诺内容与实际情况不符。若被抽查发现，可能进失信名单并影响征信。**不建议** |
| **C. 委托代理机构** | 由机构以「独立开发」口径申报 | ⚠️ 机构材料的真实性责任在你。且新规明确整治「批量代写」，机构若被查，风险传导至你 |

### 我的建议

**选 A。**

理由：
1. **软著对本次上架不是必需的** —— 华为官方《应用资质审核要求》第 3 条明确写：
   「APP 软件著作权证书为『非必选资质』，但建议您申请」。
   不申请不影响提交审核。
2. **B、C 两个选项都有实质风险**，而收益只是加分项。
3. 真正卡住上架的是账号资质、正式签名、素材质量与审核沟通 —— 这些不需要软著。

如果你有**其他必须软著的理由**（比如申报高新技术企业、拿政府补贴、参与招投标），
那软著就绕不开了。这种情况下建议：
- 咨询当地版权代办机构或主管部门，了解「人机协作开发」的实际认定口径；
- 考虑以**公司主体**申请，让技术负责人对独创性作出认定；
- 或者，等下一个版本（更多你本人主导的重构）再申请。

> 无论选哪个，**本文档与已生成的材料都可以直接复用** —— 不申请不损失什么，
> 申请时能省下 20–40 个工作日。

## 三、如果决定申请：完整流程

### 3.1 账号注册与实名认证

1. 访问 [中国版权保护中心](https://www.ccopyright.com.cn/)
2. 注册账号 → 办理业务前完成**实名认证**
   - 个人：手持身份证拍照 + 人脸识别
   - 绑定手机号
3. 耗时 **1–3 个工作日**

### 3.2 填写申请表

选择 **R11 计算机软件著作权登记申请**，在线填报。

所有字段的填写内容见 `软件主要功能描述.md` 的表格部分。几个关键点：

| 字段 | 填什么 | 注意 |
| --- | --- | --- |
| 软件全称 | 驼峰 CamelHump 本地大模型运行时软件 | **不含版本号、不含广告词** |
| 版本号 | V1.1.1 | 与源码页眉、手册封面**完全一致** |
| 开发完成日期 | 2026 年 10 月 26 日 | 填首次公开日，**不要填提交日** |
| 首次发表 | 已发表 / 2026-10-26 / 网络发布 | 网址填 GitHub 仓库 |
| 权利取得方式 | 原始取得 | 独立开发对应此项 |
| 软件主要功能 | 复制 `软件主要功能描述.md` 正文 | 1154 字，在 500–1300 区间 |
| 源程序量 | 4998 行 | 统计自研代码，不含 llama.cpp |

> ⚠️ 「开发完成日期」与「首次发表日期」若填成提交当天，可能被判定为
> 虚构日期而驳回。软著登记要求日期可验证。

### 3.3 签章页手抄（必须本人手写）

新规要求**经办人本人**（不是代理机构联系人）：

1. 使用**黑色中性笔**亲笔抄写指定的承诺段落
2. **签名**
3. **填写身份证号码**
4. 严禁打印、代签、涂改 —— 违规直接导致材料无效

> 这一步无法代办，也没有任何工具能替代。请预留时间手写。

### 3.4 上传材料

| 材料 | 要求 | 本项目对应文件 |
| --- | --- | --- |
| 源程序 | PDF，60 页，每页 ≥50 行，页眉标注软件全称与版本号，右上角页码 | `源代码.pdf` |
| 文档 | 用户手册，≥15 页，每页 ≥30 行，图文结合 | `用户手册.pdf`（17 页） |
| 身份证明 | 个人：身份证正反面扫描件并签字 | 自行准备 |
| 签章页 | 手抄承诺 + 签名 + 身份证号 | 自行手写后扫描 |

**上传前自检**（每一项不满足都可能被要求补正）：

- [ ] 源码 PDF 恰好 60 页，不是 59 或 61
- [ ] 每页代码行数 ≥50（打开 PDF 数一下，别只信脚本输出）
- [ ] 页眉「驼峰 CamelHump 本地大模型运行时软件 V1.1.1」在**每一页**都出现
- [ ] 页眉版本号与申请表**完全一致**
- [ ] 手册页眉同上，封面软件名与申请表**完全一致**
- [ ] 著作权人 `shy1658` 在申请表、源码页脚、手册封面**三处一致**
- [ ] 源码是**连续**的代码，未把多个不相关项目的代码拼在一起
- [ ] 源码中**不含** llama.cpp 等第三方代码（我们的已排除）
- [ ] 手册中的功能描述与源码中能找到对应实现
- [ ] 手册截图清晰可辨，与软件真实界面一致

### 3.5 提交与审查

```
提交 → 受理（5–7 工作日）→ 审查（受理日起 60 工作日内）→ 发证
```

- 受理后可在官网消息中心查状态
- 收到**补正通知**必须在 **30 日内**提交补正材料，**逾期视为撤回申请**
- 补正通知**只在官网消息中心发送**，不打电话 —— 这是最容易被忽略的坑
- 审查通过后下载电子证书（与纸质证书同等法律效力）

### 3.6 费用

| 项目 | 金额 |
| --- | --- |
| 官方登记费 | **0 元**（2017 年起取消新登记官费） |
| 变更/补充登记 | 150 元/件次 |
| 合同登记 | 100 元/次 |
| 加急 | 1000–5000 元不等，可缩短至 3–15 工作日 |
| 代理服务费（若委托） | 200–1500 元/件 |

**自行办理成本为零**，只有时间成本。

## 五、与上架的关系

```
软著（非必选，2-3.5 个月，可并行）
  │
  ├─→ 华为应用市场上架（可选加分，不阻塞）
  │
  └─→ 高新技术企业认定 / 双软认定 / 政府补贴 / 招投标（这才是刚需）
```

**软著不阻塞上架。** 真正阻塞上架的三件事，按优先级：

1. **华为开发者账号 + 实名认证**（1–2 天）
2. **应用创建受邀名单**（如被拦，3–5 天）
3. **正式发布证书 + `.app` 打包**（1 天）

详见 [`docs/APP-STORE-GUIDE.md`](../APP-STORE-GUIDE.md)。
